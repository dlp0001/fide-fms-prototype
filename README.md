# FIDE Management System — prototype

Clickable prototype of two connected parts:

- **FIDE Management System (FMS)** — the internal back office. Switch roles in the top bar: Secretariat, Councillor (Africa), Commission chair, Grants coordinator, Management, Treasurer, Accounting.
- **Federation Portal** — the front office for national federations, with sign-in through ChessID.

The PDC development-grant process works end to end: application, pitch booking, eligibility checks, councillor review, commission evaluation, parallel approval, agreement and e-signature, bank check and payment, final report and publication. Other modules (membership and dues, events, ratings and titles, finance) are shown as planned phases.

The guide bar under the header walks through the demo in 10 steps. "Reset demo" restores the starting data.

All federations, people and figures are mock data. The demo date is fixed at 14 April 2027.

## Run

Single static file, no build step. Open `index.html` in a browser, or enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).
